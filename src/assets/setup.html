dashboard setup

configure discord oauth2 to enable admin login:

  1. create an application at discord.com/developers/applications under oauth2.
  2. add the redirect url https://burrow.meeyah.dev/admin/callback.
  3. set BURROW_DISCORD_CLIENT_ID, BURROW_DISCORD_CLIENT_SECRET, BURROW_DISCORD_REDIRECT_URI, and BURROW_DISCORD_ALLOWED_USER_ID in .env.
  4. restart the container and reload this page.

all metrics endpoints remain hidden until sign-in is configured.
