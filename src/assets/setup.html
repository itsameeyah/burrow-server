🐇 Burrow — dashboard setup

The dashboard is Discord-gated so only Mia can open it. To finish wiring it up:

  1. Create an application at discord.com/developers/applications → OAuth2.
  2. Add redirect URIs:
    https://burrow.meeyah.dev/admin/callback (tunnel phase)
    http://192.168.0.126:8787/admin/callback (LAN phase)
  3. Set these on the Burrow server:
    BURROW_DISCORD_CLIENT_ID
    BURROW_DISCORD_CLIENT_SECRET
    BURROW_DISCORD_REDIRECT_URI (one of the above)
    BURROW_DISCORD_ALLOWED_USER_ID (your Discord user id — the one and only account that may sign in)
  4. Restart the server and reload this page — it will send you through Discord sign-in.

Until then this page exists only on your LAN / behind your token, and metrics are counts-only regardless.
